# Homework 1 — Python Basics

This assignment focuses on fundamental Python programming concepts,
including loops, conditional statements, lists, dictionaries, strings,
and basic file handling.

## Q1 — Find the Two Largest Numbers

Write a program that reads unique integers between 10 and 90 until `-1`
is entered. The program should then print the largest and second-largest
numbers.

Notebook: `Q1-two-largest-numbers.ipynb`

---

## Q2 — Prime Number Detection

Write a program that receives a positive integer and determines whether
it is a prime number.

Notebook: `Q2-prime-number.ipynb`

---

## Q3 — Simple Dictionary-Based Translator

Create a simple translator that reads word pairs into a dictionary and
then translates a sentence. Words that are not available in the
dictionary should remain unchanged.

Notebook: `Q3-simple-translator.ipynb`

---

## Q4 — Palindrome String Detection

Read a collection of strings and identify which strings are palindromes,
i.e., strings that read the same from left to right and right to left.

The program should report both the number of palindromes and their
positions in the input.

Notebook: `Q4-palindrome-strings.ipynb`

---

## Q5 — Grade Analysis from a CSV File

Read student grades from a CSV file and:

1. Calculate each student's average grade.
2. Sort students by their average grade in ascending order.
3. Calculate the overall average across students.

Notebook: `Q5-csv-grade-analysis.ipynb`
