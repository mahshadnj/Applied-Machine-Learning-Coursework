# Applied Machine Learning

This repository contains assignments, exercises, and the final project completed as part of the Applied Machine Learning course at Sharif University of Technology.

## Contents

- Machine learning exercises and assignments
- Data preprocessing and visualization
- Supervised classification
- Model evaluation and cross-validation
- Principal Component Analysis (PCA)
- Final course project on cerebral palsy gait classification

## Final Project

### Machine Learning–Based Classification of Cerebral Palsy Gait Patterns

The final project investigates the classification of four cerebral palsy gait patterns based on the Rodda classification system using sagittal-plane kinematic data from the hip, knee, and ankle joints.

Different machine learning approaches are used to evaluate classification performance and investigate the contribution of individual lower-limb joints.
